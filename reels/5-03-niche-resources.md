# Ten niche websites and archives

Browsing list for language, film, print, fashion, books and sound. Direct links checked 2026-10-11. Old Movie Title Stills URL 404ed; Patreon project page used. DC Punk Archive item count and 1902 start date unconfirmed.

Source reel: https://www.instagram.com/reel/DdPerfny6L8/

## Items

### 28. Describing Words
- kind: website
- collection: resources (Niche resources)
- link (Site): https://describingwords.io/

Type a noun to find adjectives drawn from books. Use it for writing and descriptive vocabulary.

### 29. Eternal Family
- kind: website
- collection: resources (Niche resources)
- link (Site): https://eternal.tv/

A hand-picked streaming collection of unusual and rare films, plus 24/7 channels. Access terms are on the site.

### 30. IDEA
- kind: website
- collection: resources (Niche resources)
- link (Site): https://www.ideanow.online/

London bookseller and publisher. Browse rare, vintage and new fashion, photography and art books. The current catalog is broader than the reel suggests.

### 31. Print.pm
- kind: website
- collection: resources (Niche resources)
- link (Site): https://print.pm/

Print-media inspiration: book and magazine spreads, editorial layouts and typography.

### 32. Trend List
- kind: website
- collection: resources (Niche resources)
- link (Site): https://trendlist.org/

A catalog documenting visual trends in graphic design since 2011.

### 33. Scanned Fashion World
- kind: website
- collection: resources (Niche resources)
- link (Site): https://www.scannedfashionworld.com/

Scanned fashion editorials and campaigns, including 1990s material. The reel describes it as one person’s personal archive.

### 34. The Movie Title Stills Collection
- kind: website
- collection: resources (Niche resources)
- link (Site): https://www.patreon.com/MovieTitles

Christian Annyas’s archive of film title screens. The old direct collection address returned 404 when checked; this link is the verified project page on Patreon. The reel’s 1902 start date was not independently confirmed.

### 35. An Eclectic Library
- kind: website
- collection: resources (Niche resources)
- link (Site): https://eclectic-library.neocities.org/

A hand-built index of online books, with a preference for scanned original pages. Follow its themed bookshelves to source scans; check each source’s access and rights.

### 36. DC Punk Archive
- kind: website
- collection: resources (Niche resources)
- link (Site): https://digdc.dclibrary.org/do/2b8435ca-71ba-4674-b3a4-7da2ed280c5e

DC Public Library’s punk-scene archive, established in 2014: zines, fliers, posters, photographs and recordings. The reel’s approximate item count was not confirmed.

### 37. UCSB Cylinder Audio Archive
- kind: website
- collection: resources (Niche resources)
- link (Site): https://cylinders.library.ucsb.edu/

More than 15,000 digitized cylinder recordings available for free streaming or download. The collection includes early music, spoken selections and home recordings.
