## Items

#### 356. Craft Anything (storytold/craft-anything)

[https://github.com/storytold/craft-anything](https://github.com/storytold/craft-anything) - the repo behind the reel. Open-source (Apache 2.0) clean-room reverse-engineering engine in pure Rust (320 tools; desktop app in egui, CLI, MCP server, parts run in the browser as WebAssembly). Point it at a website, app or game, say what you want, press Start: it Studies the original (pages at every width, code, files), has a coding agent Build a new project, Checks the copy against the original, and refines until Ready. Clean-room mode (default) only uses what a visitor can see; Deep mode reads the compiled code with its own disassembler/decompiler, plus Ghidra when installed. Claude Code is the first supported builder (it runs your own signed-in claude program); Codex, Copilot CLI, Grok and other ACP agents are also wired in. Requires Rust 1.97+. 38.7k stars, 7.7k forks at save; repo created 2026-10-31.

#### 357. Craft App Suite (the "rebuilt Adobe and Microsoft" claim)

[https://github.com/storytold/craft-anything#the-craft-app-suite](https://github.com/storytold/craft-anything) - the team's suite of open-source creative/office apps behind the caption's claim. PhotoCraft (image editing, real PSD files), VectorCraft (vector illustration), FilmCraft (video/color/sound), LightCraft (photo library and raw), PdfCraft, EffectCraft (motion graphics/VFX), DesignCraft (page layout), FigCraft (interface design), WordCraft, SoundCraft, DeckCraft, CADCraft, GridCraft (spreadsheets), TextureCraft, MaterialCraft; SolidCraft (parametric 3D CAD) is a community app by Tangency Labs. Adobe-side analogues: Photoshop, Illustrator, Premiere, Lightroom, Acrobat, After Effects, InDesign; Microsoft-side: Word, PowerPoint, Excel.

- [GitHub](https://github.com/NationalSecurityAgency/ghidra)

Named on screen ("GHIDRA ... created by the NSA"): the NSA's free, open-source (Apache 2.0) software reverse-engineering suite, public since March 2019, 100k stars at save. Craft Anything's Deep mode calls it when installed.
