# Motion stack for Claude Code websites

A short reel by [@jackroberts___](https://www.instagram.com/jackroberts___/) (Jack Roberts, posted 2026-10-08). Source: [original reel](https://www.instagram.com/reel/DePLcw_Dbwo/). The caption makes the argument that Claude can build a website but does not know how it should move, and names three tools to paste into Claude Code so it wires them in: GSAP, Lenis and React Bits. Hashtags: #claudecode #gsap #lenis #reactbits #webdesign.

## Items

### 119. GSAP

Animation library, named in the reel for scroll effects. The official site says GSAP is now free for everyone with Webflow's support, and covers scroll, SVG, text and UI interaction animation. Licence is GreenSock's standard no-charge licence rather than MIT.

- [Official site](https://gsap.com)
- [GitHub](https://github.com/greensock/GSAP)

### 120. Lenis

Smooth-scroll library by darkroom.engineering, named in the reel as what makes scrolling feel smooth. MIT licence.

- [Official site](https://lenis.darkroom.engineering)
- [GitHub](https://github.com/darkroomengineering/lenis)

### 121. React Bits

Animated React components and backgrounds, named in the reel for text, backgrounds and buttons. Components install as source you own (copy or CLI). The GitHub repo lists MIT + Commons Clause.

- [Official site](https://reactbits.dev)
- [GitHub](https://github.com/DavidHDev/react-bits)
