# Four GitHub repos for advanced design effects

Design creator Cindy Zhu (@cindiezhu) shows four GitHub repos for advanced design effects, to adapt with Claude Code (posted 2026-09-24, 6.1K likes, 3.2K comments): react-three-fiber (React renderer for three.js), liquid-glass-js (Apple-style liquid glass UI), shadergradient (animated shader gradients) and liquid-logo (liquid-metal logo effect). The reel is comment-bait - "comment 'repos' for all four links and the implementation guide" - so links go out by DM; the four repos were recovered from the video itself, and the DM'd implementation guide was not visible signed-out. Caption advice: a repository is reference code, not a magic asset - check licence, maintenance and framework first, then ask Claude Code to isolate the smallest effect and adapt it in a disposable branch before merging. Links checked 2026-10-11.

## 109. react-three-fiber - React renderer for three.js

Kind: website
Collection: design-effect-repos
Creator: pmndrs (Poimandres)

React renderer for the three.js 3D library; the reel's repo 1, shown for building advanced 3D effects on the web. MIT licence, actively maintained. The reel pairs it with Three.js Journey (Bruno Simon's course) as the place to learn the underlying 3D library.

- GitHub: https://github.com/pmndrs/react-three-fiber
- Docs: https://docs.pmnd.rs/react-three-fiber
- Three.js Journey: https://threejs-journey.com/

## 110. liquid-glass-js - Apple-style liquid glass for the web

Kind: website
Collection: design-effect-repos
Creator: dashersw

WebGL library bringing Apple Liquid Glass-style refraction, blur and masking to web UI elements (buttons, cards, pills); the reel's repo 2, shown with its glass button demo. MIT licence. Owner confirmed from the repo screen recording in the video; a different same-named repo exists, so the exact link matters.

- GitHub: https://github.com/dashersw/liquid-glass-js

## 111. shadergradient - customizable animated shader gradients

Kind: website
Collection: design-effect-repos
Creator: ruucm

Animated, customizable shader-gradient component for React/three.js, also available for Figma and Framer; the reel's repo 3, shown with its customizer UI (shape, motion and colour controls).

- GitHub: https://github.com/ruucm/shadergradient
- Site: https://www.shadergradient.co/

## 112. liquid-logo - liquid-metal effect for any logo

Kind: website
Collection: design-effect-repos
Creator: Paper Design

Tool that applies a liquid-metal chrome shader to any uploaded logo; the reel's repo 4, shown with chrome logo demos. GitHub lists its licence as "Other", so the caption's own advice to check the licence before reusing code applies here.

- GitHub: https://github.com/paper-design/liquid-logo
