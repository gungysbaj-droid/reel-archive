# Shaders is now open source (200+ free shaders + MCP)

Source: [original reel](https://www.instagram.com/reel/Dekiz4iRdul/).

Hype reel by @archieauburn (Archie Auburn), posted 2026-10-16 (156 likes, 56 comments at save). Caption: "Nobody was prepared for them to literally drop the entire 200+ collection of top-tier shaders for everybody to use them with no charge at all, but here we are. Shaders' custom MCP server also contributes a lot to how fascinating this project is and how easy it appears to be as a drop-in solution. Comment 'Shader' so I can send you all the links for this tool" (#shaders #opensource #coding #programming #github). The 33-second video (visually inspected frame by frame) shows the "Shaders MCP" writeup, live shader demos, the GitHub repo page (WebGPU components for React, Vue, Svelte, Solid, JS & Framer), and the shaders.com gallery grid.

Comment-bait format, but no DM is needed: the resource is fully public. The product is **Shaders** (shaders.com), which open-sourced its core on 2026-10-06 under the MIT license - the rendering engine, every shader component, and all framework bindings. Free vs paid, plainly: the shader collection, the engine and code export from the design editor are free (open source, MIT, commercial use allowed); the MCP server connects with a free account; what costs money is **Shaders Pro** (the 1,000+ pro-grade shader library, 55+ pre-built sections, high-quality video/image rendering, Discord, priority support).

## Items

#### 244. Shaders (open-source repo) - shader-effects-inc/shaders

The repo shown in the reel: WebGPU shader components for React, Vue, Svelte, Solid, vanilla JS and Framer, MIT-licensed since 2026-10-06 (~5k stars at save; topics include mcp and webgpu-shaders). Install from npm or design in the editor and export the code. The same team previously made the liquid-logo and shadergradient repos archived in r17.

- [shader-effects-inc/shaders (GitHub)](https://github.com/shader-effects-inc/shaders)

#### 245. Shaders editor and gallery - shaders.com

The site shown in the reel's gallery grid: design and customize shaders in the browser editor, then export the code for free (no account paywall for export). Hosts the free open-source component collection (the "200+" from the reel) alongside the paid Pro library.

- [Shaders](https://shaders.com/)
- [React docs](https://shaders.com/react)

#### 246. Shaders MCP server

The custom MCP server the caption highlights: lets an AI coding agent find, install and edit Shaders effects in your codebase. One-command setup (`npx shaders@latest install-mcp`) that auto-detects Claude Code, Cursor, Codex, VS Code, Windsurf, Antigravity and more, or add `https://shaders.com/mcp` manually. Free accounts can connect and install/edit shaders you design; the Pro library and Pro knowledge base require Shaders Pro.

- [Shaders MCP docs](https://shaders.com/docs/guide/mcp)
- [Installing a shader via MCP](https://shaders.com/docs/guide/installing-a-shader-via-mcp)

#### 247. "Shaders is now open source" - announcement (2026-10-06)

The team's own announcement of the open-sourcing: what went free (engine, all components, framework bindings, defineShader component language, free code export, commercial use OK) and what stays paid (Pro library, sections, video/image rendering).

- [Shaders is now open source](https://shaders.com/updates/shaders-is-open-source)
- [Pricing](https://shaders.com/pricing)
